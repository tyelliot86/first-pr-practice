# first-pr-practice

Practice repo for my first PR.

## About

This repository is a sandbox for learning the GitHub pull request workflow — creating branches, making changes, and opening PRs for review.

## How to contribute

1. Create a new branch: `git checkout -b my-branch-name`
2. Make your changes
3. Commit: `git commit -m "describe your change"`
4. Push: `git push origin my-branch-name`
5. Open a pull request on GitHub
